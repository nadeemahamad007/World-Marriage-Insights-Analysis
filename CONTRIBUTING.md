# Contributing

Thank you for your interest in this project.

This repository is primarily maintained as an academic and portfolio project, but suggestions, improvements, and cleanup contributions are welcome.

## How To Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make focused updates with clear commit messages.
4. Test your changes before submitting.
5. Open a pull request with a short explanation of what changed and why.

## Recommended Contribution Types

- Improve documentation
- Fix bugs in the dashboard or analysis scripts
- Improve code structure and readability
- Add data visualizations
- Improve model evaluation or reproducibility

## Notes

- Keep file paths project-relative.
- Avoid hardcoded local machine paths.
- Try to keep changes easy to review and well-scoped.

## Questions

If you want to suggest improvements, open an issue or submit a pull request.
